# Self-hosted interface fonts

Allowance loads these files from its own origin; there are no runtime font-service requests.

- `figtree-latin-variable.woff2`: Figtree normal, weights 300–900, Fontsource 5.3.0. Source: https://fontsource.org/fonts/figtree/cdn and https://cdn.jsdelivr.net/fontsource/fonts/figtree:vf@5.3.0/latin-wght-normal.woff2. License: `Figtree-LICENSE.txt` (SIL OFL 1.1).
- `geist-mono-latin-variable.woff2`: Geist Mono normal, weights 100–900, Fontsource 5.3.0. Source: https://fontsource.org/fonts/geist-mono/cdn and https://cdn.jsdelivr.net/fontsource/fonts/geist-mono:vf@5.3.0/latin-wght-normal.woff2. License: `GeistMono-LICENSE.txt` (SIL OFL 1.1).

Downloaded 2026-09-13. The files are unmodified; system fallbacks cover characters outside the Latin subset. Full license notices accompany the redistributed fonts.
