Read-only support checks never call `/verify`, `/settle`, `sendTransaction`, faucets or a paid model. The standard scripted smoke is prepared for 10,000 + 20,000 micro-USDC under a 40,000 allowance; its separate 20,000 probe must be denied. A model-driven run and an MCP-driven paid run require their own evidence. Payment channels remain [planned](payment-channels.md).

The remaining operational sequence is in [live setup](live-setup.md): select the durable host, configure operator/provider/account credentials privately, validate native accounts and funding, run read-only preflight, then execute only a specifically authorized bounded smoke. Static deployment does not close that gate.
