# Allowance brand

Allowance is a working product name. No trademark availability claim is made.

The original symbol uses two uprights and a horizontal ceiling. A small dot sits within that boundary: enough room to act, a limit to respect. Its geometry remains recognizable in one color at 16px. The artwork does not reuse a Solana or third-party company mark.

Editable assets: `public/allowance-symbol.svg`, `public/allowance-wordmark.svg`, and `public/favicon.svg`. The wordmark text remains editable in the SVG. Match the browser wordmark with a medium weight, generous lowercase forms, and slightly tightened tracking.

| Token           | Value     | Use                                     |
| --------------- | --------- | --------------------------------------- |
| Background      | `#F7F7F2` | Warm page background                    |
| Surface         | `#FFFFFF` | Workspaces and receipts                 |
| Ink             | `#151C19` | Main text                               |
| Secondary       | `#65706A` | Supporting text                         |
| Primary         | `#267656` | Calls to action and settled accounting  |
| Quiet lime      | `#DDEA9A` | Remaining allowance and identity accent |
| Border          | `#E2E6DE` | Soft card boundaries                    |
| Held / unknown  | `#9A661E` | Outstanding reservations                |
| Blocked / error | `#A44740` | Denied proposals and failures           |

Tokens live in `src/styles.css`. Typography uses a locally installed readable sans-serif stack (Avenir Next, Avenir, Segoe UI, Arial), avoiding remote font requests in rehearsal. Currency uses tabular numerals; request IDs use a monospace stack. Main surfaces use 18–24px corners, small controls use 8–10px corners. Motion is 180–320ms and disabled for reduced motion.

Voice: straightforward, precise, quietly encouraging. Lead with useful work and a clear boundary. A rehearsal is always called a fixture; a proposed payment never appears settled. USDC merchant costs, SOL fees/rent, and model costs remain separate. Never imply onchain budget enforcement or resistance to a compromised server.
